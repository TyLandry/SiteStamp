# Screenshots for the payroll and job sites pull request

Images for the `feature/payroll-and-job-sites` pull request (commit 1403d4b).
Not app code; this branch only hosts the pictures.

**Everything shown is fictional demo data**: the company (Northfork Builders),
the crew, addresses, phone numbers, emails, account numbers, shifts and pay.
It was served by a local stand-in for Supabase; no real database was used.
Tax rates are the real 2026 federal and Alberta tables. Pay runs were
calculated by the app itself.

Each screen at 1440 px (desktop), 768 px (tablet) and 390 px (phone, 2x):

| File | Screen |
| --- | --- |
| 01-today | Today: decisions, who's on the clock |
| 02-hours | Hours & pay: shift details with job sites and distance flags |
| 03-payroll-run | Payroll: draft pay run with holiday, vacation and deduction columns and the review panel |
| 04-pay-setup | Payroll > Employee pay setup: Alberta rules, one employee's settings and a tool loan |
| 05-year-end-t4 | Payroll > Year-end T4 summary |
| 06-job-sites | Job sites: clock-in map, flagged events, site list |
| 07-settings | Settings: company details, pay period, overtime |
| 08-crew-student | Crew & wages: minimum wage and the student option |
| 09-paystub | Finalized pay stub: employer details, vacation pay, union dues |
| 10-paystub-holiday | Draft pay stub: Remembrance Day holiday pay with its inputs |
| 11-employee-clock | Employee: on the clock at a job site |
